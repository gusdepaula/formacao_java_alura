# Formação Java: Dominando Java para Desenvolvimento Back-end 🚀

Bem-vindo à formação **Java** da **Alura**! Este repositório reúne conteúdos, projetos e desafios para quem deseja dominar Java e se tornar um desenvolvedor Back-end de alto nível.

## Sobre a Formação

A formação Java da Alura foi criada para proporcionar uma experiência completa no desenvolvimento Back-end, utilizando as melhores práticas e ferramentas do ecossistema Java. Aqui você irá aprender desde os fundamentos da linguagem até a construção de APIs robustas e escaláveis.

### O que você vai aprender?

- **Fundamentos do Java**: Sintaxe, tipos de dados, controle de fluxo, orientação a objetos.
- **Desenvolvimento Back-end**: Criação de APIs RESTful, integração com bancos de dados, autenticação e segurança.
- **Frameworks e Ferramentas**: Spring Boot, Maven, JUnit, IntelliJ IDEA.
- **Boas práticas**: Testes automatizados, versionamento com Git, Clean Code e SOLID.

## Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Maven
- JUnit
- IntelliJ IDEA
- Git & GitHub
